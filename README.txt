ROMANTIC PROPOSAL WEBSITE
==========================
1. Keep index.html and cat-card.jpg in the same folder.
2. Open index.html in Chrome/Edge to preview.
3. To publish it, upload both files to a static host such as GitHub Pages, Netlify, or Vercel.
4. To use your own photo/GIF, replace cat-card.jpg with your image and keep the same filename.

Features:
- Responsive mobile + desktop layout
- Pink/lavender romantic glassmorphism look
- Floating hearts
- Playful moving No button
- Yes -> celebration + final screen
- Reduced-motion accessibility support
